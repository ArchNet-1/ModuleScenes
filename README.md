# ArchNet · Load Scene Extension

Loads a scene from the build list on start, after a delay, or when Load() is called (e.g. from a button).

- Unity **6000.0** or newer · No dependency.
- Part of [ArchNet](https://archnet-plateform.fr), free and open-source Unity packages

## Install

*Window > Package Manager > + > Install package from git URL…*

```
https://github.com/ArchNet-1/LoadSceneExtension.git
```

## Use

Add **ArchNet > Load Scene**, pick the scene in the dropdown, set the delay. Call `Load()` from a button's OnClick, or tick *Load On Start*.
